       - Writes header row with bold formatting.
       - Writes data rows, mapping types directly: numbers as numeric cells, booleans as boolean cells, strings as string cells, nulls as blank cells.
       - Saves workbook.
    4. Implement `export_to_json(result: &QueryResult, path: &Path) -> Result<(), ExportError>`:
       - Maps rows into array of JSON objects keyed by column names and writes formatted JSON using `serde_json`.
