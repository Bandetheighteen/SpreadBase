    1. Define `SheetTable`:
       - `sheet_name: String`
       - `table_name: String` (sanitized SQL identifier)
       - `columns: Vec<String>` (header row as variables)
       - `rows: Vec<Vec<SqlValue>>`
    2. Define identifier sanitization function `sanitize_table_name(workbook_name: &str, sheet_name: &str) -> String`:
       - Replaces spaces, dashes, dots, and non-alphanumeric characters with underscores.
       - Ensures identifier starts with a letter or prefix.
       - Double-quotes identifiers for SQL compatibility.
    3. Implement `read_excel_file(path: &Path) -> Result<Vec<SheetTable>, ParseError>` using `calamine::open_workbook_auto`:
       - Iterates through all sheet names (`workbook.sheet_names()`).
       - Reads the first row as column header names. If a header is empty, assigns default `col_{index}`.
       - Iterates remaining data rows, reconciling types: numbers to `SqlValue::Double` or `SqlValue::BigInt`, text to `SqlValue::Text`, booleans to `SqlValue::Boolean`, empty cells to `SqlValue::Null`.
       - Reconciles mixed-type columns safely into text if types vary across rows.
    4. Re-export in `src/parsers/mod.rs`.
  </action>
