<task type="auto">
  <name>Task 2: Implement in-memory DbManager with query execution</name>
  <files>src/db/manager.rs, src/db/mod.rs</files>
  <read_first>
    - src/db/types.rs
    - Cargo.toml
  </read_first>
  <action>
    Create `src/db/manager.rs` implementing `DbManager`:
    1. Holds an internal `duckdb::Connection`.
    2. `DbManager::new_in_memory() -> Result<Self, DbError>` initializes an in-memory connection via `duckdb::Connection::open_in_memory()`.
    3. `execute_query(&self, sql: &str) -> Result<QueryResult, DbError>`:
       - Times execution using `std::time::Instant`.
       - Prepares statement with `self.conn.prepare(sql)`.
       - Extracts column names and types from statement metadata into `Vec<ColumnMeta>`.
       - Iterates rows via statement query, mapping DuckDB column values dynamically to `SqlValue` variants.
       - Returns `QueryResult` with populated columns, rows, count, and elapsed milliseconds.
    4. `execute_statement(&self, sql: &str) -> Result<usize, DbError>` for non-query DDL/DML statements (`CREATE TABLE`, `INSERT`, etc.).
    5. Re-export `DbManager` in `src/db/mod.rs`.
  </action>
  <verify>
    <automated>cargo check</automated>
    <fails_when>compiler errors in src/db/manager.rs</fails_when>
  </verify>
  <done>DbManager initializes in-memory DuckDB and executes arbitrary SQL queries returning structured QueryResults.</done>
</task>
