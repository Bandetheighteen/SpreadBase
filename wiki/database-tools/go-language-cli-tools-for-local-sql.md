# Go Language CLI Tools for Local SQL

> Sources: [Local SQL Queries on CSV and Excel Files](local-sql-on-csv-excel.md)
> Archived: 2026-09-28

## Overview

A summary of command-line (CLI) tools written in the Go programming language that are used for performing local SQL queries on CSV and Excel files.

## Tools

* **TextQL**: A tool similar to `q` that imports data into an in-memory SQLite database for querying and drops it immediately after.
* **CSVQ**: A fast CLI tool featuring a native, lightweight query engine that is specifically optimized for CSV operations.
